Fit statistical models, compute probability distributions, and summarize data in PHP. Model functions accept formulas or explicit designs and return fit objects that print like R’s and read like arrays.

Formulas follow R: mpg ~ wt + factor(cyl) models fuel economy from weight and the number of cylinders. phit builds the numeric design from named columns, including factors, interactions, and transformations such as log(wt). echo $fit prints the fit as R does.

use Phibble\DataFrame;use function Phit\fit_ols;$cars = DataFrame::fromCsv(    'https://raw.githubusercontent.com/phpstats/datasets/main/csv/mtcars.csv',);$fit = fit_ols('mpg ~ wt + factor(cyl)', $cars);echo $fit;

OLS, generalized linear, and mixed models also have matrix functions, such as fit_ols_matrix(), for code that builds its own design. See Model contracts.

Results

  • Coefficient names, treatment contrasts, term order, deviance, and AIC follow R’s lm() and glm(). Mixed models follow lme4. IV follows ivreg and fixest; ridge follows explicit-lambda glmnet scaling.
  • Rows with missing values are dropped with a warning, and every result reports which rows it used.
  • Errors are PHP exceptions with stable numeric codes.
  • The verification pages compare each model with R, lme4, and statsmodels and record the tolerances.

Requirements

phit runs on non-thread-safe PHP 8.3, 8.4, and 8.5 on Linux and macOS. It installs with PIE or from prebuilt Linux binaries (Installation). Where the extension cannot be installed, the plain-PHP polyfill provides every function except the CSV reader, and runs more slowly.
