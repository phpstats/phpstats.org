Fit a linear model to 32 cars, print the estimates, and predict fuel economy for cars that are not in the data.

The page runs with the extension or the plain-PHP polyfill. The data are mtcars: fuel consumption and design of 32 cars (1973–74 models) from Motor Trend. mpg is miles per US gallon, wt is weight in 1,000 lb, and am is the transmission (0 automatic, 1 manual).

Data

The formula functions take named columns: an associative array of column => list of values, with every column the same length. A table object with toModelData() or toColumns(), such as a phibble DataFrame, is also accepted. This page reads the CSV file by URL with phibble (composer require phpstats/phibble).

use Phibble\DataFrame;use function Phit\{fit_ols, predict};$cars = DataFrame::fromCsv(    'https://raw.githubusercontent.com/phpstats/datasets/main/csv/mtcars.csv',);
  • Numeric values make a numeric column.
  • Strings make a factor whose levels sort in byte order. factor() in a formula makes a numeric column a factor.
  • Model formulas lists every accepted column type.

Fit

$fit = fit_ols('mpg ~ wt + factor(am)', $cars);

mpg is the response. wt + factor(am) adds a slope for weight and a treatment-coded indicator for manual transmission, with automatic (0) as the reference level. The intercept is included unless the formula removes it with - 1 or + 0.

fit_generalized_linear(), fit_mixed_gaussian(), and fit_mixed_logistic() return the same naming and accounting keys with the statistics of their model, and summary() and tidy() take their results too. See Linear and generalized linear models and Mixed models.

Predict

predict() rebuilds the formula over new data. The response column is not needed, and factor levels are those the fit saw.

$new = ['wt' => [2.5, 3.5], 'am' => [1, 0]];$p = predict($fit, $new, interval: 'prediction');echo DataFrame::fromColumns([    'wt' => $new['wt'],    'am' => $new['am'],    'mpg' => $p['fit'],    'lower' => $p['lower'],    'upper' => $p['upper'],]), "\n";
# A tibble: 2 × 5
     wt    am   mpg lower upper
  <dbl> <int> <dbl> <dbl> <dbl>
1   2.5     1  23.9  17.3  30.5
2   3.5     0  18.6  12.1  25.1
  • interval: 'prediction' covers one new car’s fuel economy. interval: 'confidence' covers the mean.
  • A level the fit never saw, such as am 2, throws an exception with code 1001.
  • Prediction covers generalized linear and mixed-model predictions.

Missing values

null and NAN are missing. By default, a row with a missing value in any column the formula uses is dropped, and the fit emits one E_WARNING. With mpg set to null in the third row, the warning reads:

Phit\fit_ols(): dropped 1 of 32 observations with missing values (listwise deletion)
  • The result reports n_observations 31, n_input 32, and dropped_rows [2].
  • diagnostics.warnings records listwise deletion removed 1 of 32 original rows.
  • missing: 'raise' rejects missing values. The call throws an Exception with code 1001 and the message missing values found with missing='raise'.

Missing values defines which values count as missing and how rows are counted.

Errors

Invalid input and failed fits throw a PHP Exception. getCode() gives the category, for example:

Code Meaning
1001 Invalid input
1002 Mismatched lengths
1004 Rank-deficient design
