Fit reaction time on days of sleep deprivation with a random intercept for each subject, then read the fixed effects, the variance components, and each subject’s estimated effect.

The data are sleepstudy: average reaction time per day for 18 subjects in a sleep-deprivation study, days 0 to 9. Reaction is in milliseconds. The example reads the file by URL with phibble (composer require phpstats/phibble) and runs with the phit extension or the plain-PHP polyfill (Extension or polyfill).

Code

use Phibble\DataFrame;use function Phit\fit_mixed_gaussian;$sleep = DataFrame::fromCsv(    'https://raw.githubusercontent.com/phpstats/datasets/main/csv/sleepstudy.csv',);$fit = fit_mixed_gaussian(    'Reaction ~ Days + (1 | Subject)',    $sleep,);foreach ($fit['columns'] as $i => $name) {    printf(        "%-12s %7.2f (se %.2f)\n",        $name,        $fit['coefficients'][$i],        $fit['std_errors'][$i],    );}$subject = $fit['random'][0];printf(    "\nsubject SD %.2f, residual SD %.2f\n\n",    sqrt($subject['covariance'][0][0]),    $fit['sigma'],);foreach ($subject['group_labels'] as $g => $label) {    $se = sqrt($subject['effects_cond_var'][$g][0][0]);    printf(        "%s %+7.2f (se %.2f)\n",        $label,        $subject['effects'][$g][0],        $se,    );}

Interpretation

  • (1 | Subject) gives each subject an intercept of its own, assumed to come from a normal distribution. The fit uses REML, as lme4::lmer() does by default.
  • The Days coefficient is the average change in reaction time per additional day of sleep deprivation. The model gives every subject the same slope.
  • The subject SD describes how baseline reaction times vary between subjects. The residual SD describes how each subject’s days vary around their own line.
  • effects are each subject’s predicted intercept relative to the average, as R’s ranef() reports. They are shrunk toward zero, more so for subjects with fewer observations. Every subject here has ten days, so their conditional standard errors are equal.
  • In these data the slopes also differ between subjects; (Days | Subject) fits a random slope as well. See Mixed models.
