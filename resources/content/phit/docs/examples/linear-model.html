Fit fuel economy from weight and number of cylinders, then predict two cars with 95% prediction intervals.

The data are mtcars: fuel consumption and design of 32 cars (1973–74 models) from Motor Trend. mpg is miles per US gallon, wt is weight in 1,000 lb, and cyl is the number of cylinders. The example reads the file by URL with phibble (composer require phpstats/phibble) and runs with the phit extension or the plain-PHP polyfill (Extension or polyfill).

Code

use Phibble\DataFrame;use function Phit\{fit_ols, predict, summary};$cars = DataFrame::fromCsv(    'https://raw.githubusercontent.com/phpstats/datasets/main/csv/mtcars.csv',);$fit = fit_ols('mpg ~ wt + factor(cyl)', $cars);echo summary($fit), "\n";$new = ['wt' => [2.5, 3.5], 'cyl' => [4, 8]];$p = predict($fit, $new, interval: 'prediction');echo DataFrame::fromColumns([    'wt' => $new['wt'],    'cyl' => $new['cyl'],    'mpg' => $p['fit'],    'lower' => $p['lower'],    'upper' => $p['upper'],]), "\n";

Interpretation

  • factor(cyl) treats the number of cylinders as categories. Four cylinders is the reference, and factor(cyl)6 and factor(cyl)8 compare six and eight cylinders with four for cars of the same weight.
  • The wt coefficient is the difference in miles per gallon associated with 1,000 lb more weight among cars with the same number of cylinders. It describes these 32 cars, not the effect of adding weight to a car.
  • With 32 cars and correlated predictors, the standard errors are large relative to the estimates.
  • A prediction interval covers one new car’s mileage. A confidence interval (interval: 'confidence') covers the mean mileage of such cars and is narrower.
