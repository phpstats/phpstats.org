fit_ols() fits a linear model by least squares. fit_generalized_linear() fits a generalized linear model by maximum likelihood. Both take an R formula and named columns, as described in Model formulas.

Phit\fit_ols(    string $formula,    array|object $data,    string $missing = 'drop',    array|string|null $weights = null,): array;Phit\fit_generalized_linear(    string $formula,    array|object $data,    string $family = 'gaussian',    string $link = '',    string $missing = 'drop',    array|string|null $weights = null,): array;

Families and links

Family Links Response Matrix function
gaussian identity Numbers fit_ols_matrix
binomial logit (default), probit 0/1 numbers, booleans, a factor or strings (first level is failure), proportions with integer trial weights, or cbind(successes, failures) fit_logistic_matrix, fit_probit_matrix
poisson log Nonnegative integer counts fit_poisson_matrix

An empty link selects the canonical link. Any other family or link throws an Exception with code 1007, such as family 'gamma' is not supported; use gaussian, binomial or poisson.

Linear models

  • fit_ols() assumes independent errors with constant variance.
  • With weights, it fits weighted least squares, as lm(weights = ) does: each squared residual is multiplied by its row’s weight.
  • Intervals and tests use Student’s t with df_residual degrees of freedom.
  • The result adds t_statistics, rss, residual_variance, sigma, r_squared, and adj_r_squared to the shared keys.
  • fit_generalized_linear(family: 'gaussian') returns the same fit plus deviance, null_deviance, and aic, as R’s glm() reports them.

Logistic and probit regression

The examples on this page use mroz, 753 married women in 1975 from the Panel Study of Income Dynamics, and insurance, car insurance claims for 64 groups of policyholders. They read the files by URL with phibble. In mroz, lfp is yes if the woman was in the labor force, k5 is her number of children under 6, age is in years, wc is yes if she attended college, and inc is the family’s income without her earnings, in $1,000.

use Phibble\DataFrame;use function Phit\{fit_generalized_linear, predict};$mroz = DataFrame::fromCsv(    'https://raw.githubusercontent.com/phpstats/datasets/main/csv/mroz.csv',);$logit = fit_generalized_linear(    'lfp ~ k5 + age + wc + inc',    $mroz,    family: 'binomial',);echo $logit;

  • Binomial fits report z_statistics, with p-values and 95% intervals from the normal distribution (Wald inference).
  • fitted holds probabilities, and residuals holds y - fitted.
  • The dispersion is fixed at one.
  • Under complete or quasi-complete separation, where a combination of predictors divides successes from failures, no finite maximum-likelihood estimate exists. The fit throws code 1006: complete or quasi-complete separation: no finite unpenalized logistic MLE.
  • A fit near separation can converge with very large standard errors. Convergence does not show that the inference is reliable.

Poisson regression

Counts observed over different exposures take the log exposure as an offset. In insurance, Claims is the number of claims, Holders the number of policyholders, and District the district of residence, where 4 is the major cities.

$insurance = DataFrame::fromCsv(    'https://raw.githubusercontent.com/phpstats/datasets/main/csv/insurance.csv',);$poisson = fit_generalized_linear(    'Claims ~ factor(District) + offset(log(Holders))',    $insurance,    family: 'poisson',);echo $poisson;

  • With the offset, the coefficients are log rate ratios per policyholder. exp() of the (Intercept) is the claim rate in the reference district, 1.
  • Poisson fits have the same inference keys as binomial fits.
  • The model assumes the variance equals the mean. Overdispersion is not estimated or corrected. Here the residual deviance, 223.5 on 60 degrees of freedom, shows variation well beyond that assumption.

Printing a fit

echo $fit prints any model fit in the layout of R’s print(summary(fit)), as the examples above show. summary($fit) returns the same text.

  • The coefficient table follows R’s printCoefmat(digits = 4), without significance stars.
  • A linear model adds the residual standard error, R-squared, and the F statistic. A GLM adds the dispersion, the deviances, and AIC. A mixed model adds its fit criteria and random-effect variances, as lme4 prints them.

$fit->tidy(), or tidy($fit), returns the coefficient table as a Phit\Table, which prints in the layout of R’s print.data.frame() and reads by column. The columns are term, estimate, std_error, statistic, and p_value. confInt: true adds conf_low and conf_high at level (default 0.95):

  • The intervals are Wald intervals. They use t with df_residual degrees of freedom for fits that report t statistics, and the normal distribution otherwise.
  • For mixed fits, tidy() gives the fixed effects by default. effects: 'ran_vals' gives each group’s random effects with group, level, term, estimate, and std_error columns, as broom.mixed does.

Result keys

fit_generalized_linear() with the binomial or Poisson family returns:

Key Contents
coefficients, std_errors, z_statistics, p_values, conf_int, covariance Wald inference, in columns order
fitted, residuals Fitted means and response residuals, one per retained row
log_likelihood, deviance, null_deviance, aic Likelihood statistics as R’s glm() reports them
df_residual, iterations, converged Residual degrees of freedom and Newton iterations

formula, response, columns, terms, assign, intercept, named, predvars Formula and naming keys, shared by all formula fits
n_input, n_observations, n_dropped, retained_rows, dropped_rows Sample accounting
diagnostics converged, solver, iterations and warnings

Each family’s matrix function in Model contracts defines these quantities exactly, including the null-deviance baseline and the convergence rule.

Weights and offsets

  • weights is an array aligned with the original rows, or the name of a numeric column.
  • Weights must be positive. A missing weight drops its row.
  • For fit_ols() and the Poisson family they are precision (prior) weights. For the binomial family they are integer trial counts, with the response given as proportions.
  • Offsets are written in the formula with offset(expr). Several offsets are added together.

Differences from R

  • A rank-deficient design throws code 1004. R reports aliased coefficients as NA.
  • Zero weights are rejected. R gives such rows zero weight.
  • Binomial and Poisson covariances are the inverse information at the final coefficients. R’s vcov() uses the IRLS weights of the iteration before the final one, so standard errors differ by about the size of R’s last step, up to about 1e-4 relative near separation. See GLM covariance.
  • Gaussian fit_generalized_linear() intervals use t, as fit_ols() does. R’s confint.default() uses z and confint() profiles the likelihood.

Model formulas lists the remaining differences in formula handling.
