Keep the penguins with a recorded body mass, and add the mass in kilograms and a size label to each. penguins has size measurements for 344 penguins near Palmer Station, Antarctica, from 2007 to 2009 (Gorman et al., 2014).

  • PHP 8.5+
  • PHP 8.3–8.4
use Phibble\DataFrame;use function Phplyr\{filter, select, mutate, if_else, col};$data = 'https://raw.githubusercontent.com/phpstats'    . '/datasets/main/csv';$penguins = DataFrame::fromCsv("$data/penguins.csv");echo $penguins |>    filter(fn ($r) => $r->body_mass_g !== null) |>    select('species', 'island', 'sex', 'body_mass_g') |>    mutate(        mass_kg: fn ($r) => $r->body_mass_g / 1000,        size: if_else(            col('body_mass_g')->ge(4500),            'large',            'small',        ),    );
use Phibble\DataFrame;use function Phplyr\{phplyr, if_else, col};$data = 'https://raw.githubusercontent.com/phpstats'    .   • filter() keeps the rows for which the row closure returns true. Two penguins have no recorded mass, so 342 rows remain.
  • select() keeps four columns, and mutate() adds one column for each named argument.
  • A row closure such as fn ($r) => $r->body_mass_g / 1000 runs once per row and reads the row’s columns as properties.
  • A column expression such as col('body_mass_g')->ge(4500) works on the whole column, and if_else() uses it to pick 'large' or 'small'.
  • sex is NA for some penguins. Missing values print as <NA>.
