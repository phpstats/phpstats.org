A typical R analysis of the penguins data, translated to PHP. It reads a CSV file, cleans and reshapes it, summarizes it, and fits a linear, a logistic, and a random-intercept model.

Data: penguins, size measurements for 344 penguins near Palmer Station, Antarctica, read by URL. The R script needs dplyr, tidyr, and lme4. The PHP script needs phplyr and, for the models, phit; see Models.

R

suppressPackageStartupMessages({  library(dplyr)  library(tidyr)  library(lme4)})data <- paste0("https://raw.githubusercontent.com/phpstats",               "/datasets/main/csv")penguins <- read.csv(file.path(data, "penguins.csv"),                     na.strings = c("", "NA")) |>  as_tibble()# Clean: drop incomplete rows, band body mass,# compute the bill ratio.clean <- penguins |>  filter(!is.na(body_mass_g), !is.na(sex)) |>  mutate(    mass_band = case_when(      body_mass_g < 3500 ~ "light",      body_mass_g < 4500 ~ "mid",      .default = "heavy"    ),    bill_ratio = bill_length_mm / bill_depth_mm,    male = as.integer(sex == "male")  )# Reshape: one row per penguin and bill measure.long <- clean |>  mutate(penguin = row_number()) |>  select(penguin, species, length = bill_length_mm,         depth = bill_depth_mm) |>  pivot_longer(c(length, depth), names_to = "measure",               values_to = "mm")long |>  group_by(measure) |>  summarise(mean = mean(mm), sd = sd(mm))# Summarize: penguins per species and mass band, then# the species by mean bill ratio.clean |>  count(species, mass_band) |>  pivot_wider(names_from = mass_band, values_from = n,              values_fill = 0)clean |>  group_by(species) |>  summarise(n = n(), mean_ratio = mean(bill_ratio)) |>  arrange(desc(mean_ratio))# Model: linear, logistic, and random-intercept fits.fit_lm <- lm(body_mass_g ~ flipper_length_mm + male,             data = clean)fit_glm <- glm(male ~ body_mass_g + bill_depth_mm,               family = binomial, data = clean)fit_lmer <- lmer(  body_mass_g ~ flipper_length_mm + male + (1 | species),  data = clean)round(coef(fit_lm), 4)round(coef(fit_glm), 4)round(fixef(fit_lmer), 4)

What changed in translation

  • Loading. read.csv() becomes DataFrame::fromCsv(), which infers column types like readr and reads empty fields as NA, as na.strings = c("", "NA") does in R.
  • Pipes. On PHP 8.5, R’s |> stays |>. On PHP 8.3 and 8.4, the pipeline becomes a method chain that starts with phplyr($t).
  • Column references. Bare names become strings, or col('x') inside expressions, so bill_length_mm / bill_depth_mm becomes col('bill_length_mm')->div(col('bill_depth_mm')).
  • Conditions. case_when(x < 4 ~ "low", .default = "high") becomes case_when([col('x')->lt(4), 'low'], default: 'high').
  • Renaming in select. select(length = bill_length_mm) becomes select(['length' => 'bill_length_mm']).
  • Column sets. c(length, depth) becomes ['length', 'depth'].
  • Models. lm(), glm(), and lmer() take the same formulas. They return arrays, so coef() and fixef() become reads of coefficients. The coefficients agree to the printed four decimals, except the last digit of the random-intercept model’s intercept.
  • Printing. DataFrames print in tibble’s format.

On a database table from Phibble\tbl(), the cleaning, counting, and grouped-summary steps run as SQL, because they use col() expressions and phplyr’s helpers. The reshaping step loads the rows into PHP. See Databases and expressions.
