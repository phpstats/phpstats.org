  • The 26,115 rows give 16 columns. rownames holds the row names the table had in R.
  • Whole numbers, such as year, hour, and wind_dir, become int, where readr’s read_csv() gives double. Decimals become double.
  • time_hour holds ISO 8601 text such as 2013-01-01T06:00:00Z, which is guessed as a datetime in UTC.
  • types declares origin a factor, with the levels EWR, JFK, and LGA in sorted order. Without it, origin would be a string.
  • Empty fields become NA: one hour has no temperature, 20,778 of 26,115 have no wind gust, and 2,729 have no pressure.
  • Types are guessed from up to 1,000 sampled rows. Declare a type when those rows could mislead the guess.

Runnable script: read-a-csv.php. It reads the file over HTTPS, so allow_url_fopen must be on.
