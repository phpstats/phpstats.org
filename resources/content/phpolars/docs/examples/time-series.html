Give each departure from JFK the latest temperature reading at or before its scheduled time, with a mean of the readings over the previous three hours.

The data are hourly weather and all departures at New York City airports in 2013, from the R nycflights13 package (weather and flights), read by URL. Temperatures are in degrees Fahrenheit.

Requires the phpolars extension (Getting started). Runnable script: time-series.php.

use function Phpolars\{col, datetime, read_csv, scan_csv};$data = 'https://raw.githubusercontent.com'    .'/phpstats/datasets/main/csv';$jfkJan1 = [    col('origin')->eq('JFK'),    col('month')->eq(1),    col('day')->eq(1),];$at = fn (string ...$parts) => datetime(    ...array_map(fn ($p) => col($p), $parts),);// Hourly temperature at JFK, with a 3-hour rolling mean.$weather = read_csv("$data/weather.csv", columns: [    'origin', 'year', 'month', 'day', 'hour', 'temp',])    ->filter(...$jfkJan1)    ->select($at('year', 'month', 'day', 'hour')        ->alias('time'), 'temp')    ->sort('time')    ->withColumns(        col('temp')->rollingMeanBy('time', '3h')            ->round(1)            ->alias('temp_3h'),    );// Departures scheduled from 12:55 to 13:10.$flights = scan_csv("$data/flights.csv", nullValues: 'NA')    ->filter(...$jfkJan1)    ->select('carrier', 'flight', $at(        'year', 'month', 'day', 'hour', 'minute',    )->alias('scheduled'))    ->filter(col('scheduled')->dt()->strftime('%H:%M')        ->isBetween('12:55', '13:10'))    ->sort('scheduled')    ->collect();echo $flights->joinAsof(    $weather,    leftOn: 'scheduled',    rightOn: 'time',);

  • joinAsof() takes the last reading whose time is on or before each scheduled time.
  • JFK has no reading at 12:00 on January 1, so the departures before 13:00 get the 11:00 reading.
  • Both inputs must be sorted by their join columns. Unsorted input raises an InvalidOperationError.
  • The '3h' window is (time - 3h, time]: it includes the row’s own reading and excludes the one three hours earlier.
  • A missing reading leaves the window three hours long, with fewer readings in it. At 13:00 the window holds only the 11:00 and 13:00 readings.
  • rollingMean(3) would average the last three readings, whatever their times.
  • scan_csv() filters the flights while reading them, and collect() returns a DataFrame for the join.
