Installing

phpolars runs on PHP 8.3, 8.4, and 8.5, non-thread-safe (NTS) builds, on Linux and macOS. Install it with PIE, PHP’s extension installer:

pie install phpstats/phpolars

On Linux on x86_64 and arm64 with glibc 2.34 or later, PIE downloads a prebuilt binary. On other platforms, including macOS, it builds the extension from source, which needs a stable Rust toolchain and libclang and takes several minutes. PIE then enables the extension in php.ini. Under PHP-FPM, restart FPM afterwards so that its workers load the extension. Deployment covers servers, Laravel Forge, Laravel Herd, and manual installs.

Checking the installation

php -r 'echo phpversion("php_polars"), PHP_EOL;'

The command prints the installed version, such as 0.2.2. It checks the CLI. PHP-FPM reads its own php.ini, so check a web request separately, for example with extension_loaded('php_polars') in a page.

A starter script

phpolars needs no Composer packages. Download the example data, penguins.csv: body measurements of 344 penguins near Palmer Station, Antarctica, from the R palmerpenguins package (penguins). Missing values are written NA.

mkdir phpolars-start && cd phpolars-startcurl -fsSLO https://raw.githubusercontent.com/phpstats/datasets/main/csv/penguins.csv

Runnable script: starter.php.

Imports

Classes such as Phpolars\DataFrame live in the Phpolars namespace, and so do the functions, which need use function. The examples on this page use these:

use function Phpolars\{col, len, lit, read_csv, scan_csv, when};

The examples below read the same penguins.csv, with nullValues: 'NA' so that NA entries become nulls.

Strings passed where py-polars expects an expression input, such as select(), name columns. Use lit() for a string value there. In comparisons and arithmetic, strings are literals: col('island')->ne('Torgersen'). A when() chain without otherwise() gives null where no condition holds, as for the penguin without a body mass.

Lazy queries

A DataFrame runs each method immediately. A LazyFrame records operations and runs them when collect() is called. scan_csv() creates a lazy query. Polars optimizes the column selection and the filters before running it, so the reader converts only the columns that the query uses and drops filtered rows as it parses them. The reader still reads the whole file. Query a large CSV file lazily walks through a query plan.

$query = scan_csv('penguins.csv', nullValues: 'NA')    ->filter(col('body_mass_g')->gt(4500))    ->groupBy('species')    ->agg(len()->alias('penguins'))    ->sort('species');echo $query->explain(), "\n\n";echo $query->collect();
SORT BY [col("species")]
  AGGREGATE[maintain_order: false]

Missing values

phpolars follows Polars: a missing value is null, aggregates such as sum() and mean() skip it, and null sorts first. phibble and phplyr follow R and dplyr instead. phibble and phplyr compares the two.
