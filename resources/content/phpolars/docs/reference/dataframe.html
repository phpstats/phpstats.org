DataFrame holds data in memory and runs each operation immediately. LazyFrame records operations and runs them, optimized, on collect(). Both have the same methods; a DataFrame method builds a lazy query and collects it, as py-polars does.

Creating data frames

$df = new DataFrame(['a' => [1, 2], 'b' => ['x', 'y']]);          // columns$df = new DataFrame([['a' => 1, 'b' => 'x'], ['a' => 2, 'b' => 'y']]);  // rows$df = DataFrame::fromRows([[1, 'x'], [2, 'y']], schema: ['a' => 'Int32', 'b' => 'String']);$df = new DataFrame(['a' => new Series('a', [1, 2])]);$df = read_csv('data.csv');$lf = $df->lazy();      // or scan_csv(), scan_parquet(), ...

A schema argument names columns and sets their types.

Joins

join() takes on, or leftOn and rightOn, and how: inner, left, right, full, semi, anti, or cross. suffix names clashing right-hand columns, coalesce merges key columns, nullsEqual lets null keys match, and maintainOrder (none, left, right, left_right, right_left) fixes the row order.

The example joins JFK departures on January 1, 2013, to airport names, from the R nycflights13 package (flights and airports). Four destinations, in Puerto Rico and the US Virgin Islands, are not in airports.

Iterating over groups

A GroupBy works with foreach, as py-polars’ does. The key is a list of the group’s key values, and the value is the group’s rows as a DataFrame:

foreach ($penguins->groupBy('species', maintainOrder: true) as $key => $rows) {    echo $key[0], ': ', $rows->height(), "\n";}

Time series

groupByDynamic() groups rows into fixed time windows, and rolling() gives each row a window that ends at it. joinAsof() matches each row to the nearest earlier (or later, or nearest) row of another data frame, optionally within by groups and a tolerance. Durations are py-polars strings such as '1d', '2h30m', '1w', and '1mo'. Expressions add the rolling*By() family and ewmMean(). The functions date_range() and datetime_range() build calendars. The examples below use hourly weather at JFK in 2013 from the R nycflights13 package (weather), read by URL. Rolling windows and as-of joins shows joinAsof().
